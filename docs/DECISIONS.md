# Engineering decision index

This index makes accepted engineering choices discoverable. The linked issue
entry owns the reasoning; this file is not a duplicate ADR store. Status describes
the decision, not consumer adoption or deployment. Add entries when relevant new
work is accepted; do not fabricate historical reasoning.

available authorization/review evidence; this index does not invent an earlier
ADR approval comment. New replacements get their own linked entries.
